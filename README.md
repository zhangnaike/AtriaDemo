# AtriaDemo · 墨晓 Ink Dawn

提交给 **Atria Demo 共建** 的作品：**一语成应用**（One Prompt, One App）。

一句话，生成完整可运行的应用——左侧流式输出代码，右侧应用从无到有长出来。

## 快速开始

```bash
cd web && npm install && npm run dev
# 打开 http://localhost:3000/demo
```

详细说明见 [Demo说明.md](./Demo说明.md)，视频分镜见 [录制脚本.md](./录制脚本.md)。

## 亮点

- 三个真实模型生成的完整应用：打砖块游戏（727 行）/ 数据看板（722 行）/ 品牌官网（502 行）
- 流式回放工作台：逐字输出 + iframe 实时联动 + 倍速控制
- 墨晓 Ink Dawn 视觉主题：纯黑底 + 黎明金橙渐变

> 演示说明：代码为模型真实输出，播放为受控回放（非实时 API 调用），详见 Demo说明.md 第五节。
